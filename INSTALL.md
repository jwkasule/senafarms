# Installation / Deployment Notes for SenaFarms

This file expands on the Quick Start in README.md with environment examples and deployment hints.

Prerequisites
- PHP >= 7.0 with extensions: OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON
- Composer
- Node.js >= 8 and npm
- MySQL (or other DB supported by Laravel)
- Optional: Redis for queue/broadcast caching, Pusher credentials for realtime

Local setup (recommended)
1. Clone your fork and install PHP dependencies

```bash
git clone https://github.com/jwkasule/senafarms.git
cd senafarms
composer install --no-interaction --prefer-dist
```

2. Install frontend dependencies and build assets

```bash
npm install
npm run dev    # development build
# or for production assets
npm run production
```

3. Environment file

Copy the example .env and edit values for your environment:

```bash
cp .env.example .env
```

Example .env snippets (edit to match your DB/mail/pusher creds):

```
APP_NAME=SenaFarms
APP_ENV=local
APP_KEY=            # generated by artisan
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=senafarms
DB_USERNAME=root
DB_PASSWORD=

BROADCAST_DRIVER=pusher
PUSHER_APP_ID=your-pusher-id
PUSHER_APP_KEY=your-pusher-key
PUSHER_APP_SECRET=your-pusher-secret

MAIL_DRIVER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=null
```

4. Generate application key and run migrations

```bash
php artisan key:generate
php artisan migrate
php artisan db:seed   # optional, will run seeders
```

5. Serve locally

```bash
php artisan serve --port=8000
# visit http://127.0.0.1:8000
```

Heroku / Platform notes
- A Procfile is provided in the repository. On Heroku set the buildpacks to support PHP and Node.js (Heroku can detect both when dependencies are present).
- Set required config vars via the platform dashboard or CLI (APP_KEY, DB_*, PUSHER_* , MAIL_*).
- You may want to run database migrations during release phase or via a manual one-off dyno:

```bash
heroku run php artisan migrate --app your-heroku-app
```

- Build frontend assets either during slug compilation (npm install + npm run production) or prebuild locally and commit the production assets into the repo.

Security & file permissions
- Ensure storage/ and bootstrap/cache are writable by the web server.
- Never commit .env with secrets to the repository.

Backup & logs
- Logs are in storage/logs/laravel.log
- Backup your DB regularly; use mysqldump or your hosting provider's backups.
